# TrendSniper · 趋势选股系统（实时行情）

把《趋势策略.md》的选股体系完整落地为**可运行、可回测、会自我调优**的本地网站。

> 覆盖板块：**沪主板 / 深主板 / 创业板 / 科创板 / 北证**（全 A 市场 5500+ 只）
> 数据全部来自**实时行情接口**（新浪快照 / 腾讯K线·现价 / 东方财富报告期财报），**无任何模拟数据**。

## 一、Git 与部署（服务器代码放在 /root）

仓库：`git@github.com:wangchaoqunnnn/TrendSinper.git`

```bash
# 在服务器上执行（代码将被克隆到 /root/TrendSinper）
cd /root
git clone git@github.com:wangchaoqunnnn/TrendSinper.git
cd TrendSinper

# 依赖：仅需 Python 3.8+ 标准库（无第三方包）
python3 -m backend.main status          # 自检

# 前台运行
./run.sh --host 0.0.0.0 --port 8765

# 或后台运行（关闭终端不退出）
nohup ./run.sh --host 0.0.0.0 --port 8765 > nohup.log 2>&1 &
```

Windows 双击 `启动选股系统.bat` 即可本地运行。

> 端口可用环境变量覆盖：`TRENDSNIPER_PORT=9000 ./run.sh`。
> 项目内所有路径均为相对路径、运行时动态解析，可克隆到任意目录（/root、/home 等）直接运行，
> 页面与 API 也全部使用相对地址，不依赖固定域名或端口。

## 二、功能与页面

| 页面 | 说明 |
|---|---|
| 今日选股 | 全市场实时扫描：选择理由（赛道/基本面/技术面逐条中文）、止损价与止损依据、信号价、评分、板块与行业；一键重跑 |
| 回测与统计 | 历史逐日重放选股→持有→离场：**成功率、盈亏比**、利润因子、每笔期望、最大回撤、资金曲线、按板块/离场原因分组 |
| 策略自调优 | 每周自动“回测→随机搜索参数→训练窗择优→验证窗确认”，验证窗显著更优才采纳并升级版本号（防过拟合） |
| 虚拟持仓跟踪 | 每次选股自动开虚拟仓，按止损价/破MA20/持有超时自动平仓，长期积累真实口径样本 |
| 定时任务 | 交易日收盘后自动选股；每周自动回测+自调优；启动时补跑逾期任务 |
| 策略说明 | 原始策略文本与“中文策略 → 量化规则”映射、统计口径 |

界面规范：
- **所有表格**：点击表头即可按该列升/降序排列（再次点击反向），首列自动为 **No** 编号；
- 页面与图表文字均做留白与防重叠处理。

## 三、策略 → 代码 映射（详见页面「策略说明」）

1. **自上而下找赛道** → `sector`：行业内 ≥4 只样本、≥30% 站上 MA60、20 日板块均涨 ≥2%（行业归属来自最新财报接口）
2. **基本面筛选** → `fundamental`：ROE / 归母净利同比 / 营收同比（东方财富最新报告期全市场自动抓取）
3. **技术面确认** → `ma_bull`（价>MA20>MA60>MA120 且 MA60 上行）、`new_high`（创 60/120/250 日新高）、
   `pullback_rising`（回调低点抬高）、`volume`（上涨温和放量/回调缩量）、`month_ret`（月涨幅区间）、
   `turnover`（换手适中）、`relative_strength`（跑赢沪深300）、`anti_weak`（大盘下跌日抗跌）
4. **实战选出 + 风控** → 加权打分排序、入选门槛、单板块 50% 上限、自动放宽标注；
   **止损价 = max(MA20×98%，近10日回调低点×98%，买入价×(1-止损8%))** —— “买卖看支撑，破位坚决跑”

评分权重与阈值集中存放 `data/strategy_params.json`（版本化），自调优只微调参数、不改策略骨架。

## 四、数据与延迟优化

| 数据 | 主源 | 缓存策略 |
|---|---|---|
| 全市场快照 | 新浪 hs_a（并行翻页 ~6s） | 进程内 300 秒缓存 |
| 个股/指数日K（前复权） | 腾讯行情 | SQLite 持久化，命中零网络 |
| 业绩报表 + 行业归属 | 东方财富数据中心（分页并行） | 每天刷新一次 |
| 批量现价 | 腾讯 qt.gtimg | 进程内 10 秒缓存 |

全市场K线拉取为 10 路并发；选股与回测复用同一份本地K线缓存，二次运行不再请求网络。

## 五、统计口径

- 回测：每 4 个交易日全市场打分一次（与实盘同规则同参数），信号日收盘买入；离场：破止损价（跳空按开盘价）/ 收盘破 MA20 / 持有超时 / 期末平仓；计入双边成本。
- **成功率** = 盈利笔数 ÷ 已平仓总笔数；**盈亏比** = 平均盈利 ÷ 平均亏损。
- 资金曲线为“等权名义仓位（1/12）逐笔累乘”示意净值；回测中基本面采用当前最新报告期数据（报告中已注明前视偏差）。
